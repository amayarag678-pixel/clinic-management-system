# 🏥 Clinic Management System

A modern and responsive **Clinic Management System** developed using **HTML, CSS, Bootstrap, and JavaScript**.  
This project provides separate dashboards and management modules for **Patients, Doctors, and Administrators** to simplify clinic operations and improve healthcare management.

---

## 🌐 Live Demo

🔗 https://clinic-management-system-5bbb06.netlify.app/

---

## ✨ Features

### 👤 Patient Module
- Patient Login
- Appointment Booking
- Queue Management
- Appointment History
- Patient Dashboard

### 👨‍⚕️ Doctor Module
- Doctor Login
- Patient Management
- Schedule Management
- Consultation Overview
- Doctor Dashboard

### 🛡️ Admin Module
- Admin Login
- Manage Doctors
- Reports & Analytics
- System Control Panel
- Clinic Overview Dashboard

## 🚀 How to Run the Project

1. Download or clone the repository

```bash
git clone https://github.com/your-username/clinic-management-system.git
```

2. Open the project folder in VS Code

3. Install the **Live Server** extension

4. Right-click `index.html`

5. Click:

```plaintext
Open with Live Server
```
